# A Class to Represent Rational Numbers with Operators Overload

## Overload the Arithmetic Operators for Rational Numbers

Overloads the following operators:

* `-Rational`
* `Rational + Rational`
* `Rational - Rational`
* `Rational * Rational`
* `Rational / Rational`
* `Rational += Rational`
* `Rational -= Rational`
* `Rational *= Rational`
* `Rational /= Rational`
* `Rational = Rational`
* `Rational == Rational`
* `Rational != Rational`
* `Rational > Rational`
* `Rational >= Rational`
* `Rational <= Rational`
* `Rational < Rational`

The class has the following data members:
```c++
int _numerator, _denominator;
```
And the following constructors:
```c++
Rational(int numerator, int denominator);
Rational(double number); // If you don't implement it set _numerator to 0 and _denominator to 1
```
